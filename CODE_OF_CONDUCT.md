# Code of conduct · 行为准则

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

本项目遵循[贡献者公约 2.1 版](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/)。

In short: be respectful and constructive, welcome newcomers, and assume good faith. Harassment,
insults and personal attacks are not tolerated in issues, pull requests, discussions or any other
project space.

简而言之：保持尊重与建设性，欢迎新人，善意地理解他人。在 Issue、Pull Request、讨论区等任何项目空间中，都不容许骚扰、辱骂和人身攻击。

Report unacceptable behavior privately to the maintainers through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Maintainers may remove, edit or reject contributions and temporarily or permanently ban
contributors whose behavior they deem inappropriate.

如遇不当行为，请通过 GitHub 的举报功能私下告知维护者。维护者有权删除、编辑或拒绝相关内容，并可视情况暂时或永久禁止相关人员参与。

# Test fixtures

| File | Contents |
| --- | --- |
| `encrypted-user-password.pdf` | One page, AES-256 encrypted. User password `safemark`, owner password `owner-secret`. |
| `encrypted-owner-only.pdf` | One page, AES-256 encrypted with an owner password only (opens without a password). |

Both were generated with the `encrypt()` method of
[`@cantoo/pdf-lib`](https://www.npmjs.com/package/@cantoo/pdf-lib) (a pdf-lib fork that supports
encryption), which is not a dependency of this project:

```js
const doc = await PDFDocument.create()
doc.addPage([420, 300]).drawText('Password: safemark', { x: 40, y: 200, size: 22 })
doc.encrypt({ userPassword: 'safemark', ownerPassword: 'owner-secret' })
fs.writeFileSync('encrypted-user-password.pdf', await doc.save())
```

Other test documents (sample photo, multi-page and rotated PDFs) are generated by the app itself
or inside the tests.
